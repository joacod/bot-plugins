# Weekly review routine

Suggested schedule: once a week on a weekday afternoon, for example Thursday 16:00 (cron `0 16 * * 4`). Set the time zone and schedule to whatever suits the user; nothing here assumes a specific zone.

## Prompt (paste as-is, adjust the folder if needed)

Review the lessons folder in the box workspace (`lessons/`) following the Fleet self-learning skill.
Read every area file. Promote any pattern seen 3 or more times to a rule. If a newer signal contradicts a rule, demote it to a pattern and flag it; the user's latest explicit statement wins. Move rules not used or confirmed in the last 30 days to `lessons/archive/`, never delete anything. If several bots are set up, note lessons that could help related bots, as suggestions only.
Apply new or changed rules to the skill or memory that owns them, keeping each rules section short (about 40 lines), each rule with a short reason and date.
Then send me, in this chat, one short digest: rules applied, patterns forming, conflicts needing my call. If nothing changed, send nothing.
