# Lessons

One file per area. Append-only, one line per signal. Old rules go to `archive/`; nothing is deleted.

## Entry format
`YYYY-MM-DD | bot or group | signal | what changed | level`

- signal: correction / edit / reaction / explicit
- what changed: a quote or short diff
- level: example / pattern(n) / rule

Example:
`2026-01-15 | writer-bot | edit | removed closing summary paragraph | pattern(2)`

## Levels
- example: one instance, never a rule
- pattern(n): seen in n different pieces
- rule: 3+ sightings, user approval, or explicit always/never
